# Architecture Decision Records (ADR)

This folder captures durable frontend architectural decisions.

## ADR Index
- `0001-auth-session-strategy.md`: JWT client-session strategy and persistence policy.
- `0002-data-fetching-and-caching.md`: React Query data-access and cache policy.
- `0003-state-management-strategy.md`: Global state boundaries and ownership.

## ADR Format
- Context
- Decision
- Consequences
- Status (`Accepted`, `Superseded`, `Deprecated`)
